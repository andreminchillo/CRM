# SportsCRM - Discloud

## Instalação
1. Faça upload de todos os arquivos para o Discloud
2. Configure o discloud.config com seu ID
3. Inicie a aplicação

## Funcionalidades
- 135 contatos da Corrida Construai
- 1 evento configurado
- API WASeller integrada
- Interface web funcional

## Endpoints
- GET / - Interface principal
- GET /api/contacts - Listar contatos
- GET /api/events - Listar eventos
- POST /api/waseller/contacts - Sincronizar WASeller
